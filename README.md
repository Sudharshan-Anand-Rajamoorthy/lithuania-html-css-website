## Included pages

- `index.html` — professional landing page showcasing all projects
- `exercise1.html` — Lithuania profile page
- `exercise2.html` — weather information page
- `exercise3.html` — CSS practice page
- `weather_clean.html` — clean responsive weather landing page with two alternate themes

## Files

- `style1.css` — first clean light theme
- `style2.css` — alternate slate blue theme
- `style3.css` — green layout styling exercise
- `styles.css` — portfolio landing page styling

## How to view locally

Open any `.html` file in a browser, or run a local static server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000/
```

## Project purpose

This project demonstrates:

- semantic HTML structure
- clean CSS styling and layout
- responsive design patterns
- styling variation with alternate themes
- attention to readability and visual hierarchy
